## 3. 理论延迟模型

基于实测数据拟合的延迟模型：

```
Matmul latency:   L_matmul(N) = 0.065521 × N^0.250 + -0.3391
Triton LUT fill:  L_lut(g)    = 0.0079 × g  ms
PyTorch LUT fill: L_lut(g)    = 0.0645 × g  ms
Assembly:         L_asm       = 0.0174  ms  (constant)
```

其中：
- `N` = active output channels (≤ hidden_size)
- `g` = number of replaced groups
- `α = 0.250`：matmul N 维度的 scaling 指数（极低，说明 latency 主要由 M×K 和固定开销决定）
- `L_fixed = -0.3391 ms`：matmul 的固定开销（launch/kernel setup），即使 N→0 也无法消除
