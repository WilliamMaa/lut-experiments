8. v1.2 的具体实验设计

我建议你跑三种：

A. Additive LUT, local MSE
delta = LUT1[a1] + LUT2[a2] + b
loss = MSE + 0.1 * cosine
B. Additive LUT, initialized from joint bucket decomposition

把 joint bucket table T[a1,a2] 近似分解成：

T[a1,a2] ≈ A[a1] + B[a2] + b

这个可以用最简单的 ANOVA-style 初始化：

b = mean(T)
A[i] = mean_j T[i,j] - b
B[j] = mean_i T[i,j] - b

然后再训练。

这一步非常值得做，因为它能回答：

joint 2D bucket 的效果到底来自两个 address 的可加效应，还是来自真正的二阶交互？

如果 additive 分解接近 joint bucket，说明 group 4 的规律比较可分解。
如果差很多，说明 a1/a2 之间存在强 interaction。

C. Additive + small interaction table

如果 B 不够好，再加一个小交互项：

delta = LUT1[a1] + LUT2[a2] + LUTc[coarse_a1, coarse_a2]

比如 coarse bins = 8×8：

LUTc: [8, 8, group_dim]

这仍然比 64×64 小很多，但能捕获一些二阶交互。
