v1.1：Learned Codebook / Soft-to-Hard LUT

核心思路：

不再把 activation 用 uniform bin 固定切开，而是学习一组 codebook centers。
每个 token 的 activation state 先匹配最近的 center，再查对应 LUT value。
训练时可以用 soft assignment，推理时再 hard assignment。

现在的方式：

a1, a2 → uniform bin → LUT[bin1, bin2]

v1.1 改成：

address vector z = [a1, a2]
→ nearest learned centroid c_k
→ LUT[k]

训练阶段：

softmax(-distance(z, c_k) / temperature)
→ weighted sum of LUT values

推理阶段：

argmin distance(z, c_k)
→ hard lookup

这个方向比普通 trainable LUT 更有理论依据，因为它优化的是“离散状态划分”，不是只优化每个固定桶里的输出均值。

4. 为什么这比你现在的 trainable LUT 更可能有效？

因为你现在的 bucket table 其实已经是这个固定分桶下的强 baseline。

对每个 bucket 来说：

LUT[bucket] = mean(targets in bucket)

在 MSE 下已经接近最优常数解。

所以 trainable table 还能提升的空间很小。

要提升，必须改变这三个东西之一：

1. bucket 怎么划分
2. 一个输入可以组合几个 bucket value
3. 优化目标是不是只看 local MSE

其中最根本的是第 1 个：bucket 怎么划分。

Uniform bucket 只是按数值范围切，但 LLM activation 的语义结构未必按 uniform scalar range 分布。更合理的是让 codebook 学：

哪些 activation states 对 mlp_delta_group 的输出贡献相似？

这就是 learned codebook 的意义。

5. v1.1 具体怎么做，别太复杂

先不要做全高维 codebook。你现在已经证明 2-head 有效，所以 v1.1 可以只用 2D address：

z = [a_head1, a_head2]

然后学习 K 个 centroid：

K = 64 或 128
centroids: [K, 2]
table: [K, group_dim]

训练输出：

weights = softmax(-||z - c_k||^2 / τ)
y_pred = Σ weights_k * table_k

loss：

L = MSE(y_pred, target_mlp_delta_group)
  + α * cosine_loss
  + β * entropy/codebook_usage regularization

部署时：

k = argmin ||z - c_k||^2
y_pred = table[k]

这样推理仍然可以变成：

read two scalar activations
nearest centroid / 或预量化索引
lookup vector
add back
